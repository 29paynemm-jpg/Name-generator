# Random Name Generator

A small, dependency-free name generator made with plain HTML, CSS, and JavaScript.

## Run it

1. Clone or download this project.
2. Open `index.html` in a web browser.

No installation, server, or build step is required.

## Use it

- Select **Generate a name** to combine a random first name and last name.
- Enter one name per line under **Pick from your list**, then select **Pick a name**.
- Blank lines in your list are ignored.
